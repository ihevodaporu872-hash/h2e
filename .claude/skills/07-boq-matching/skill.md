# BOQ Matching Skill - Construction Scope Classification

## When to Use
- Matching BOQ line items to construction cost categories
- Classifying positions for tender analysis
- Grouping cost changes by engineering scope
- Improving semantic matching in BOQ comparison

## Role
Senior PTO Engineer / Construction Estimator (Moscow practice)

## Hierarchical Scope Structure

```
Level 1 (Main Scope)
└── Level 2 (Sub-scope, optional)
    └── Level 3 (Specific category)
```

## Matching Checklist

- [ ] Identify primary material/work type
- [ ] Check for structural vs finishing
- [ ] Check for internal vs external
- [ ] Match to Level 1 scope
- [ ] Narrow to Level 3 if possible
- [ ] Verify against keyword mapping
- [ ] Assign confidence score

## Confidence Scoring

| Score | Meaning |
|-------|---------|
| 95-100 | Exact match, no ambiguity |
| 85-94 | High confidence, clear indicators |
| 70-84 | Good match, some interpretation needed |
| 50-69 | Moderate confidence, multiple options |
| <50 | Low confidence, manual review needed |
